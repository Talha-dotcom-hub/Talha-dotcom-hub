## `05` — Featured projects

A small selection of projects that reflect my interests in repository analytics, practical AI, and data-driven applications.

<div align="center">

<img width="100%" src="assets/project-repopulse.svg" alt="RepoPulse — illustrative project graphic for GitHub repository analytics"/>

</div>

**[RepoPulse](https://github.com/Talha-dotcom-hub/RepoPulse)**

A GitHub repository intelligence platform for exploring repository metadata, activity, commits, issues, pull requests, releases, and more.

**Technologies:** React, TypeScript, Vite, Tailwind CSS, GitHub REST API.

[Live Demo](https://repopulseai.netlify.app/) · [Source Code](https://github.com/Talha-dotcom-hub/RepoPulse)

<br/>

<div align="center">

<img width="100%" src="assets/project-datalens-ai.svg" alt="DataLens AI — illustrative project graphic for privacy-first CSV analytics"/>

</div>

**[DataLens AI](https://github.com/Talha-dotcom-hub/datalens-ai)**

A privacy-first CSV analytics application that performs data profiling and calculations in the browser, with Gemini-assisted query planning and explanations.

**Technologies:** React, TypeScript, Vite, browser-based data processing, Netlify Functions, Google Gemini.

[Live Demo](https://datalenslab.netlify.app/) · [Source Code](https://github.com/Talha-dotcom-hub/datalens-ai)

<br/>

<div align="center">

<img width="100%" src="assets/project-agentic-jobs.svg" alt="Agentic Jobs — illustrative project graphic for resume-aware job discovery"/>

</div>

**[Agentic Jobs](https://github.com/Talha-dotcom-hub/Agentic-Jobs)**

A resume-aware job discovery workspace for matching opportunities to a candidate profile and organizing saved jobs and applications. Automated scans and notifications depend on backend and provider configuration.

**Technologies:** React, TypeScript, Vite, Node.js, Express, Supabase, PostgreSQL, Google Gemini.

[Live Demo](https://agenticjobs.netlify.app/) · [Source Code](https://github.com/Talha-dotcom-hub/Agentic-Jobs)

<br/>

<div align="center">

<img width="100%" src="assets/project-ecommerce-retention.svg" alt="E-Commerce Customer Retention — illustrative project graphic for customer cohort and RFM analytics"/>

</div>

**[E-Commerce Customer Retention & RFM Analytics](https://github.com/Talha-dotcom-hub/ecommerce-customer-retention)**

An analytics dashboard for exploring customer cohorts, repeat-purchase behavior, retention patterns, and RFM-based customer segments using a synthetic retail dataset.

**Technologies:** Python, pandas, NumPy, SQL, DuckDB, SQLAlchemy, Streamlit, Plotly, pytest.

[Live Demo](https://talha-ecommerce-retention.streamlit.app/) · [Source Code](https://github.com/Talha-dotcom-hub/ecommerce-customer-retention)
